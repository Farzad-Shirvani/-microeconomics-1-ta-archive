# Workshop 2: Lagrangian Optimization

## Overview

This workshop introduces the Lagrange method for constrained optimization and demonstrates its applications to consumer and producer problems. It also walks through the steps involved in setting up and solving a Lagrangian optimization problem.

## Learning Objectives

By completing this workshop, students should be able to:

- Formulate a constrained optimization problem using the Lagrange method.
- Set up the Lagrangian function and derive its first-order conditions.
- Solve the resulting system of equations for the optimal choices.
- Apply the method to consumer and producer optimization problems.
