# Workshop 1: Calculus Foundations & Unconstrained Optimization

## 📌 Overview
This workshop covers the fundamental calculus concepts required for microeconomic modeling, focusing on partial derivatives, unconstrained optimization, and basic constrained optimization using substitution.

## 🎯 Learning Objectives
- Calculate partial derivatives of multivariate functions (e.g., Cobb-Douglas utilities/production functions).
- State and apply First-Order Conditions (FOC: $f'(x)=0$) and Second-Order Conditions (SOC).
- Solve constrained optimization problems using the substitution method.
