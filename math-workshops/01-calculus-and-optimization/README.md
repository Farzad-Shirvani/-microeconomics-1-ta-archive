# Workshop 1: Calculus and Optimization

## Overview

This workshop covers differentiation of common functions, partial derivatives, the main conditions for maxima and minima, and the substitution method for constrained optimization.

## Learning Objectives

By completing this workshop, students should be able to:

- Differentiate common types of functions.
- Calculate partial derivatives of multivariable functions.
- Apply the main first- and second-order conditions for identifying maxima and minima.
- Solve constrained optimization problems using the substitution method.
