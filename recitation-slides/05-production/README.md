# Topic 05: Production Theory

## 📌 Overview
This module covers production functions in the short run and long run, marginal and average products, isoquants, Marginal Rate of Technical Substitution ($MRTS$), and returns to scale.

## 📁 Files in this Directory
- [Production_Lecture.pdf](./Production_Lecture.pdf) — Review slides on technological constraints and production functions.
- [Production_Exercises.pdf](./Production_Exercises.pdf) — Practice problems on returns to scale and optimal factor combination.
- [Production_Solutions.pdf](./Production_Solutions.pdf) — Step-by-step solution manual.

## 🎯 Learning Objectives
- Understand the Law of Diminishing Marginal Returns in the short run.
- Distinguish between diminishing marginal returns and returns to scale (IRS, CRS, DRS).
- Derive the $MRTS_{L,K}$ and verify technological properties (homogeneity and homotheticity).
