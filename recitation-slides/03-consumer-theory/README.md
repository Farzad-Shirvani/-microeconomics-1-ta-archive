# Topic 03: Consumer Theory (Preferences & Utility)

## 📌 Overview
This module explores consumer preferences, indifference curves, marginal rate of substitution ($MRS$), budget constraints, and constrained utility maximization.

## 📁 Files in this Directory
- [Utility_Lecture.pdf](./Utility_Lecture.pdf) — Conceptual recitation slides covering preference axioms and utility functions.
- [Utility_Exercises.pdf](./Utility_Exercises.pdf) — Problem sets covering Cobb-Douglas, perfect substitutes, and perfect complements.
- [Utility_Solutions.pdf](./Utility_Solutions.pdf) — Detailed analytical derivations and solution manual.

## 🎯 Learning Objectives
- Formulate and solve utility maximization problems subject to budget constraints.
- Graphically and algebraically handle interior vs. corner solutions.
- Derive Marshallian demand functions from underlying preference structures.
