# Recitation Sessions & Lecture Slides

This directory contains the weekly recitation materials, conceptual review slides, in-class practice questions, and detailed solution manuals prepared and presented by **Mahya AliAkbari** (Head TA) for **Principles of Microeconomics I**.

---

## 🎯 Objectives & Methodology
The recitation sessions were designed to:
1. **Bridge Theory and Application:** Translate abstract theoretical models introduced by Prof. Ghasemi into applied economic intuition.
2. **Interactive Problem Solving:** Work through challenging in-class questions before students tackled independent homework assignments.
3. **Exam Preparation:** Familiarize students with standard problem-solving patterns and analytical derivations.
