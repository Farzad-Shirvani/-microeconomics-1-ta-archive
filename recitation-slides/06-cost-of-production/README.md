# Topic 06: The Cost of Production

## 📌 Overview
This session covers short-run and long-run cost curves, cost-minimization conditions (isocost lines), and the relationship between production technology and cost functions.

## 📁 Files in this Directory
- [Cost_Lecture.pdf](./Cost_Lecture.pdf) — Recitation slides on cost concepts, expansion paths, and economies of scale.
- [Cost_Exercises.pdf](./Cost_Exercises.pdf) — In-class analytical problems on short-run and long-run cost derivations.
- [Cost_Solutions.pdf](./Cost_Solutions.pdf) — Complete solution manual with graphical illustrations.

## 🎯 Learning Objectives
- Formulate the cost-minimization problem using the condition: $\frac{MP_L}{w} = \frac{MP_K}{r}$.
- Derive total, average, and marginal cost curves ($TC, ATC, AVC, MC$) algebraically from production functions.
- Understand the envelope theorem and how the Long-Run Average Cost ($LRAC$) curve relates to Short-Run Average Cost ($SRAC$) curves.
